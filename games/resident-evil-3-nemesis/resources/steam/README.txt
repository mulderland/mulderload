Resident Evil 3: Nemesis *Steam Enhancement Pack* @ mulderland.com
------------------------------------------------------------------------------------------------------------------------

1) What this pack does:

- Downgrades the Steam version to the latest GOG version (v1.0 Hotfix 4) for better compatibility
- Fixes Steam game time tracking, Steam Overlay, Steam Input, etc.
- Installs Classic REbirth v1.0.3 in a new "rebirth" subfolder
- Patches the Classic REbirth executable to allow 4GB of memory
- Installs Modern Control Mods (Modern Controls Plus, Quick Knife Mod)
- Installs Translation Patches
- Installs Graphical Improvements (see below)
- Installs High Quality FMVs (see below)
- Installs High Quality Audio (see below)
- Installs MulderConfig

------------------------------------------------------------------------------------------------------------------------

2) Details

2.1) About the Graphical Improvements

This is a mix of 3 mods:
- Resident Evil 3 HD Mod (by TeamX)
- Seamless HD Project v2 (by RESHDP)
- RE-Enhance RE2 v101 (by SonicB00M)

The first two were repacked to remove "hi-res" textures that would be overwritten by the third one.
(priority order: Resident Evil 3 HD Mod < Seamless HD Project < RE-Enhance)

------------------------------------------------------------------------------------------------------------------------

2.2) About the High Quality FMVs

There are 3 options:
- RE-Enhance FMV Pack v1.1 (by SonicB00M): currently the best available pack, in 960p
- FMVs extracted from Resident Evil 3 HD Mod (by TeamX): very good quality/size ratio, in 960p
- FMVs extracted from the Sourcenext DVD (untouched), in 480p

Is it not mandatory to install a FMV pack, but highly recommended as original FMVs are in 160p

------------------------------------------------------------------------------------------------------------------------

2.3) About the High Quality Audios

This is a repack of this one:
https://archive.org/download/resident-evil-classic-trilogy-hd-mod/Resident%20Evil%203%20-%20Classic%20REbirth%20HQ%20%5BOST%20%26%20OST%20ARRANGED%5D%2008-11-2023.zip/
I've keeped the "Lossless" version (as default), and the "Dreamcast" version (my personal choice, altough they are very similar)
